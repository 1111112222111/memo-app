## 概述

一个 Windows 桌面极简便签工具。解决"打开备忘录太慢、分类太麻烦"的痛点。常驻屏幕右下角，一键滑出，输入即存，自动分类。

> **🆕 2026-05-18 更新**：新增主题切换、剪贴板监听、快捷键自定义、面板常驻、窗口拖动功能。
> **🆕 2026-05-18b 更新**：新增剪贴板图片保存、备忘录内容复制到剪贴板功能。
> **🆕 2026-05-25 更新**：新增快捷功能页面与运行器、标题系统、文件路径支持、批量清空、Warm Ink 设计系统重构、开机自启动。

## 面板布局

### 原有结构

- **输入框**：顶部，`Enter` 保存，`Esc` 关闭面板/清空输入
- **类型标签**：全部 / 链接 / 待办 / 文字，自动分类 + 可手动切换
- **记录列表**：标签下方，按时间倒序（置顶优先），显示最近 50 条
- **搜索过滤**：在"全部"标签下输入即搜，匹配已有记录，`Enter` 新建
- **记录操作**：悬停显示操作按钮（完成✓、复制📋、置顶📌、改类型、删除✕）
- **🆕 内容复制** `2026-05-18b`：每条记录悬停时显示复制按钮，文字记录复制文本，图片记录复制图片到剪贴板
- **🆕 标题显示** `2026-05-25`：链接条目显示抓取的网页标题（粗体），下方显示原始 URL；其他类型可手动添加/编辑标题
- **🆕 文件路径点击** `2026-05-25`：文件路径条目点击后在资源管理器中打开

### 🆕 新增 `2026-05-18`

## 数据模型

### Memo

```typescript
interface Memo {
  id: string;           // 时间戳+随机数
  content: string;      // 原始内容（图片类型时为文件名）
  type: 'link' | 'todo' | 'text' | 'clipboard' | 'image' | 'runner';  // 🆕 runner 类型 2026-05-25
  imagePath?: string;   // 🆕 图片本地路径（仅 type=image）
  title?: string;       // 🆕 自定义标题 2026-05-25（链接自动抓取，其他类型手动添加）
  targets?: string[];   // 🆕 运行器目标列表 2026-05-25（仅 type=runner）
  createdAt: number;    // Unix 时间戳
  pinned: boolean;      // 置顶（默认 false）
  done: boolean;        // 待办完成（仅 type=todo 时有效）
}
```

### 🆕 Settings `2026-05-18`

```typescript
interface Settings {
  theme: 'dark' | 'light' | 'system';    // 默认 'dark'
  hotkey: string;                         // 默认 'CommandOrControl+Shift+M'
  clipboardEnabled: boolean;              // 默认 false
  autoStart: boolean;                     // 🆕 开机自启动 2026-05-25
}
```

## 🆕 主题系统 `2026-05-18`

- CSS Custom Properties 定义暗色/亮色两套变量
- `[data-theme="dark"]` / `[data-theme="light"]` 切换
- 支持三种模式：暗色、亮色、跟随系统
- 跟随系统时监听 `prefers-color-scheme` 变化自动响应
- 主题切换时通过 IPC 同步 Electron 窗口背景色（暗 `#1a1a2e` / 亮 `#f5f5f8`）

## 🆕 剪贴板监听 `2026-05-18`

- 轮询间隔 800ms
- 检测剪贴板文本变化，自动创建 `type: 'clipboard'` 记录
- 🆕 检测剪贴板图片变化，保存为 PNG 至 `userData/images/`，创建 `type: 'image'` 记录 `2026-05-18b`
- 图片通过 MD5 哈希去重，相同图片连续复制仅记录一次
- 相同内容连续复制仅记录一次（去重）
- 设置面板中的开关控制启停
- 开启后工具栏显示 📋 图标，标签栏新增"剪贴板"和"图片"分类

## 🆕 运行器 `2026-05-25`

- **创建**：点击 ＋ 创建新的运行器项目，默认标题"未命名运行"
- **标题编辑**：点击运行器标题进入编辑模式，Enter 保存 / Esc 取消
- **目标绑定**：输入网址或文件路径，回车或点击 + 添加到目标列表；点击 … 按钮浏览本地文件选择
- **目标展示**：标签式排列，每个目标可 × 删除
- **一键运行**：点击 ▶ 运行按钮，依次打开所有绑定的目标（文件路径用 `shell.openPath`，网址用 `shell.openExternal`）
- **删除**：删除按钮移除整个运行器项目
- 运行器数据通过 `type: 'runner'` 和 `targets` 字段持久化

## 🆕 标题系统 `2026-05-25`

- **链接自动抓取**：新建链接类型条目时，GET 请求网页提取 `<title>` 标签内容作为标题（5s 超时，64KB 上限，跟随重定向）
- **手动添加/编辑**：悬停条目时显示"标题"按钮，点击进入编辑模式；已有标题的条目点击标题文字可编辑
- **非链接条目**：点击"添加标题"后在原位置展开输入框，输入后 Enter/失焦保存
- 标题通过 `memo:titleFetched` IPC 事件异步推送到渲染进程

## 🆕 文件路径支持 `2026-05-25`

- 输入内容匹配文件路径格式时自动归类为"链接"
- 支持格式：Windows 绝对路径 (`C:\...`、`D:\...`)、UNC 路径 (`\\...`)、Unix 路径 (`/...`、`~/...`)
- 点击文件路径条目时通过 `shell.openPath` 在资源管理器/默认应用中打开
- 复制内容时通过 `clipboard:skipNext` 跳过剪贴板监听，防止内部复制循环

## 🆕 批量清空 `2026-05-25`

- **触发**：右键任意分类标签（包括"全部"）
- **菜单**：弹出式上下文菜单，显示"清空 N 条未置顶记录"
- **执行**：点击菜单项后，通过 `memo:deleteMultiple` IPC 批量删除该分类下所有未置顶且非 runner 的条目
- **关闭**：点击菜单外任意位置或按 Esc 关闭菜单
- **保护**：置顶条目永远不会被清空

## 存储策略

- 启动时加载 JSON 文件到内存
- 每次增/删/改后异步写入文件（debounce 500ms）
- 最多保留 500 条记录，超出后删除最早的

| 文件 | 路径 | 备注 |
|------|------|------|
| 备忘录数据 | `%APPDATA%/memo-app/memos.json` | 原有 |
| 🆕 设置数据 | `%APPDATA%/memo-app/settings.json` | `2026-05-18` |
