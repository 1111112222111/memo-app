**创建日期**: 2026-05-15
**状态**: 持续迭代

## 概述

一个 Windows 桌面极简便签工具。解决"打开备忘录太慢、分类太麻烦"的痛点。常驻屏幕右下角，一键滑出，输入即存，自动分类。

> **🆕 2026-05-18 更新**：新增主题切换、剪贴板监听、快捷键自定义、面板常驻、窗口拖动功能。
> **🆕 2026-05-18b 更新**：新增剪贴板图片保存、备忘录内容复制到剪贴板功能。

## 面板布局

### 原有结构

- **输入框**：顶部，`Enter` 保存，`Esc` 关闭面板/清空输入
- **类型标签**：全部 / 链接 / 待办 / 文字，自动分类 + 可手动切换
- **记录列表**：标签下方，按时间倒序（置顶优先），显示最近 50 条
- **搜索过滤**：在"全部"标签下输入即搜，匹配已有记录，`Enter` 新建
- **记录操作**：悬停显示操作按钮（完成✓、复制📋、置顶📌、改类型、删除✕）
- **🆕 内容复制** `2026-05-18b`：每条记录悬停时显示复制按钮，文字记录复制文本，图片记录复制图片到剪贴板

### 🆕 新增 `2026-05-18`

- **工具栏**：面板右上角，包含剪贴板状态图标（📋）、常驻按钮（📌）、设置入口（⚙）
- **剪贴板标签**：开启剪贴板监听后，标签栏新增"剪贴板"标签，独立展示剪贴板捕获的内容
- **设置面板**：点击 ⚙ 进入全屏设置页，包含主题切换、快捷键录制、剪贴板开关

## 数据模型

### Memo

```typescript
interface Memo {
  id: string;           // 时间戳+随机数
  content: string;      // 原始内容（图片类型时为文件名）
  type: 'link' | 'todo' | 'text' | 'clipboard' | 'image';  // 🆕 image 类型
  imagePath?: string;   // 🆕 图片本地路径（仅 type=image）
  createdAt: number;    // Unix 时间戳
  pinned: boolean;      // 置顶（默认 false）
  done: boolean;        // 待办完成（仅 type=todo 时有效）
}
```

### 🆕 Settings `2026-05-18`

```typescript
interface Settings {
  theme: 'dark' | 'light' | 'system';    // 默认 'dark'
  hotkey: string;                         // 默认 'CommandOrControl+Shift+M'
  clipboardEnabled: boolean;              // 默认 false
}
```

## 🆕 主题系统 `2026-05-18`

- CSS Custom Properties 定义暗色/亮色两套变量
- `[data-theme="dark"]` / `[data-theme="light"]` 切换
- 支持三种模式：暗色、亮色、跟随系统
- 跟随系统时监听 `prefers-color-scheme` 变化自动响应
- 主题切换时通过 IPC 同步 Electron 窗口背景色（暗 `#1a1a2e` / 亮 `#f5f5f8`）

---

## 🆕 剪贴板监听 `2026-05-18`

- 轮询间隔 800ms
- 检测剪贴板文本变化，自动创建 `type: 'clipboard'` 记录
- 🆕 检测剪贴板图片变化，保存为 PNG 至 `userData/images/`，创建 `type: 'image'` 记录 `2026-05-18b`
- 图片通过 MD5 哈希去重，相同图片连续复制仅记录一次
- 相同内容连续复制仅记录一次（去重）
- 设置面板中的开关控制启停
- 开启后工具栏显示 📋 图标，标签栏新增"剪贴板"和"图片"分类

---

## 🆕 快捷键自定义 `2026-05-18`

- 设置面板中点击快捷键输入框进入录制模式
- 按下目标组合键后自动保存并切换
- 支持 `Ctrl/Alt/Shift + 任意键`
- 旧快捷键自动解绑，新快捷键即时生效

## 存储策略

- 启动时加载 JSON 文件到内存
- 每次增/删/改后异步写入文件（debounce 500ms）
- 最多保留 500 条记录，超出后删除最早的

| 文件 | 路径 | 备注 |
|------|------|------|
| 备忘录数据 | `%APPDATA%/memo-app/memos.json` | 原有 |
| 🆕 设置数据 | `%APPDATA%/memo-app/settings.json` | `2026-05-18` |

## 非功能需求

- 启动时间 < 2s
- 内存占用 < 150MB
- 面板展开动画 60fps
